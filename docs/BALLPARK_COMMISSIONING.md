# Private BALLPARK commissioning

RP024 adds an unreleased guided draft, protected owner decision, compact shared
codec, atomic publisher and local Qt owner review. The default desktop continues
to deny runtime activation. Trusted production composition must supply live adapters; RP053 integrates the
WATCHDOG UI and RP061 qualifies coordinated release eligibility. RP029 covers
ongoing descriptor evolution. No saved boolean or UI selection supplies authority.

`GuidedBallpark` uses the actual RP007 selector and a verified closure containing
`skill/tb4/operations/setup-r2.md`. A new draft resolves fresh instructions; restart
fetches its original immutable closure and checks current eligibility without
switching revisions. The real profile remains UNRELEASED with an empty build list.
Synthetic tests explicitly provide an eligible source; they do not release it.

Safe proposals contain only known opaque device IDs and role/platform/launch/
transport choices. Partial proposals survive restart; missing choices are listed
without names, addresses, hints, root IDs or credential bindings. Selection is not
capability proof or enrollment. Unknown platform information remains UNKNOWN.
Blank discovery produces no fabricated device or automatic scan. The local owner
chooses topology and approves the exact candidate. Interfaces and observations
stay unasserted; protected discovery retains endpoint data separately. A collector
interface is not a fact about the remote machine's own interfaces.

The local Qt review dialog is available only when a trusted commissioned Publisher
factory is supplied to SetupController. It shows allowlisted controls and opaque
aliases, with separate draft approval, publication and inspection actions. Provider
operations run outside the event thread; duplicate actions and closing during a
running operation are blocked. Pending publication offers inspection only. The
installed SKILL remains the existing pointer.

The compact codec adds `ballpark` to existing target catalogues. Its closed array
contains codec/revision, role indices, OS/architecture indices, role-matched launch
indices and transport indices; choices retain their order. Discovery ID/alias and
all existing artifact/enrollment fields are preserved. No capability/health claim
is reconstructed from owner choices. Registry records carry selected slot indices,
shared descriptor digest and instruction/build/exact-decision provenance. Settings
carry the same revision and timing. One guarded CAS commits these together.
Decode only from one validated authority snapshot. RP009 byte budgets are unchanged;
full serialized key/envelope/body overflow is rejected before pending save/write.

Publication requires commissioned root/artifacts, current WATCHDOG capability and
owner/force checks, compatible pinned instructions, exact prior shared revision,
and selected identities already published by discovery. Untouched catalogue rows
and the commissioning marker are guarded. No work/result/cancel/ACK/history record
is modified. UNKNOWN work does not block role takeover and is never replayed here.

The existing protected settings frame persists the exact frozen operation before
START. Lost replies/local failures leave the prior active descriptor unchanged.
Restart only inspects that same operation. Exact shared revision/digest/provenance
confirmation permits updating the local active descriptor, even if a successor has
taken the WATCHDOG role in the meantime. A newer/different/unavailable revision
stays UNKNOWN; it cannot silently authorize another write. Cancel/rollback/general
setup choices cannot erase or rebind pending/confirmed provenance. An interrupted
unsent write may conservatively remain UNKNOWN; later authorized reconciliation
must prove its result, not blindly replay it.

The legacy v1 PARK_MAP remains untouched and is never a default source of R2
identity, topology, authority or migration. Native Docs/folder authority adapters
remain the already commissioned storage boundary. These tests do not claim a live
Google deployment, migrated installation or ready target execution.
