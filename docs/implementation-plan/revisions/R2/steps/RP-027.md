# RP-027 - Reconfiguration of an existing deployment

Status, dependencies and requirement links: `../manifest.yaml`. [Mandatory work contract](../../../../development/WORK_INSTRUCTION.md) applies, including implementation authorization, per-check evidence and interruption handling. Checkboxes are a manifest projection.

**Deliverable / handoff:** A staged, resumable reconfiguration transaction for settings/root/capability changes.

**Inputs to inspect:** Existing private profiles and configuration backups; commissioned revision contract. Historical runtime values are not current facts. New artifacts below are planned, not already implemented.

Owner network-table direction: [RP-026 amendment A-001](../amendments/RP-026/A-001-local-network-table.md). Consume its protected local table, configurable location, deterministic device descriptions and optional stable-IP status; network configuration is not a prerequisite.

Same-authority staging and optional unreleased marker: [RP-027 amendment A-001](../amendments/RP-027/A-001-staged-same-authority.md). Maintenance gates ordinary work; leadership renewal and first-CAS stale takeover remain available without all-peer acknowledgements. Foundation source alone does not accept a check.

Inherited operation evidence and local runtime reservation: [RP-027 amendment A-002](../amendments/RP-027/A-002-shared-effect-evidence.md). Shared UNKNOWN evidence survives fallback; covered zero-blocker evidence can permit explicit routing resolution without contacting the former owner. Legacy unjournaled later epochs cannot be inferred from an empty local checkpoint.

Protected first-run candidate: [RP-027 amendment A-003](../amendments/RP-027/A-003-protected-first-run-candidate.md). The complete original profile is archived once; a separate actual Setup preserves identity and operation history and uses actual Prerequisites/CommissionedStorage. Root relocation, cache rebuilding and final promotion remain later qualified work.

Exact existing Docs root moves: [RP-027 amendment A-004](../amendments/RP-027/A-004-existing-docs-root-moves.md). Per-file native intent/shared UNKNOWN and unique metadata witnesses preserve inspect-only recovery and the same fixed objects; physical moves alone do not activate routing. Folder move, inherited/proven non-dispatch settlement and final remote rebind/promotion remain required.

Durable dispatch disposition: [RP-027 amendment A-005](../amendments/RP-027/A-005-durable-root-disposition.md). Exact protected PREPARED/INVOKING/REVOKED phases distinguish pre-send native revocation evidence from ambiguous requests without clearing UNKNOWN or granting replay. Shared settlement remains separately qualified work.

Cloud-only inherited root receipt: [RP-027 amendment A-006](../amendments/RP-027/A-006-cloud-inherited-root-settlement.md). Fresh current role may verify the exact unique after-witness and complete an older receipt without the old host/WAL/ACK. Partial-plan continuation and final first-run/routing promotion remain separately qualified work.
