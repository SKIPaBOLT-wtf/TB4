## Exact first-run composition

The trusted native_folder_prerequisites factory returns the exact existing
Prerequisites and CommissionedStorage with RemoteFolderCommissioning over a new
NativeFolderConnection. Construction reads the actual protected selection but
does not open a credential key, send a proof, select/enroll credentials or write
profiles. Legacy Prerequisites construction defaults to no guard; its original
validation body remains unchanged as _validate.

An optional internal guard is accepted only as exact NativeFolderFirstRun bound
to that checker. Caller payload must equal the complete current native profile.
Actual immutable endpoint, pointer, installation, pending state, selected explicit
FOLDER_PROBE purpose and native bindings are checked. Each attempt restores a
fresh actual native credential pair from the current image. The default pair is
bound to this exact protected Folder endpoint; a trusted program factory may
supply separately commissioned native target ports. Profile data never selects
code. Untyped/non-native/nonempty pairs refuse; no key selection or new handle is
created.

The existing environment, real storage proof, all selected credential capabilities,
descriptor, timing and compatible instruction checks still execute. Before
returning an actual Validation, full protected bytes/pins are reread and every
selected capability is rechecked with another fresh native pair. A change during
instruction or factory calls refuses readiness. Failed attempts clear the checker
credential cache. Native locks are released before the existing proof acquires its
own endpoint/profile locks; no nested lock or automatic recovery occurs.

Setup.review alone retains its existing readiness revision save and full previous
profile. Restart invalidates the memory grant and repeats verification. Identity,
nonce, image, pointer, history and work remain. Existing local UNKNOWN holds Setup
routing/activation review, while the separate connection still permits read and
first-CAS election without former-owner/all-peer acknowledgements. Default
DenyActivation remains.
