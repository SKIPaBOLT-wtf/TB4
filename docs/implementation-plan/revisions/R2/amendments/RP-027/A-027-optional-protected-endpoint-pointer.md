# RP-027 amendment A-027 — optional protected endpoint pointer

This adds capability-neutral private pointer syntax and seed preservation for
the A026 immutable endpoint frame. Actual attachment and trusted authenticated
first-run/authority composition remain separate work.

## Independent scheduling

Immutable request26 Linux/full/package inspections still qualify only source
87ca92c4417ae0a3647d08b9a05d4baedb7f7c1d. The scheduling record374 permits this
format/seed-only unit independently: it uses accepted private Setup/candidate
foundations and never invokes or changes A026 native endpoint operations.
No pending result is treated as acceptance or as a later-source qualification.

## Closed optional private field

The existing version1 Setup frame may carry folder_endpoint, absent or null by
default. A non-null value contains exactly schema_version1, opaquefe reference,
explicitly selected absolute native-local root syntax and binding_digest.
The path and digest are protected installation data, never public discovery,
credential reports or a general default topology. A structural validator copies
the bounded deterministic data and rejects additional READY/command/credential
fields, malformed identifiers, relative/noncanonical/traversing/UNC/URI paths.

Syntax validation performs no filesystem/native lookup. A nonexistent or later
unavailable root remains syntactically valid metadata, never access proof.
The future attacher must require owner authorization and exact fresh native
frame/profile/reference/binding checks; the future consumer must repeat them.
No attachment API, credential use, proof, authority, runtime allowlist or
activation is added here.

## Preservation and rollback

Profiles without the field retain the exact old encoding and seed semantics;
newly created profiles do not gain it automatically. Explicit null means no
selection. Candidate.seed copies an existing pointer by value, with original
installation, nonce, choices and operation history. Full original archival and
all existing derived-cache rules remain. Candidate schema and its pinned digest
are unchanged; old absent-field archive/seed hashes therefore remain valid.

Ordinary stopped settings rollback must preserve the same optional pointer.
A different root/reference/digest cannot be restored silently; all prior
identity/storage/history/credential and stopped-state guards still apply.
This does not introduce an endpoint migration or recovery operation.

## Held acceptance

Portable shape/compatibility/non-grant cases and affected original native and
candidate regressions require separate source-linked test evidence. Actual
native attachment/recovery, combined proof/authority first-run, runtime/GUI,
declared platform/topology/package/common gates and RP-027.C1-C4 remain held.
No former-owner or all-peer ACK requirement is added to role takeover.
