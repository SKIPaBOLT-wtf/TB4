# IP-60 Amendment A-001 - Desktop development before private testing

Date: 2026-09-29.

The owner explicitly requested separate WATCHDOG and FETCHER installers and tray
applications, development before deployment, and a first private test with both
roles on one workstation. This is an authorized scope/order change, not an attempt
to pass the old independent-machine criterion with a same-host test.

Supersede IP-60 without deleting its historical prerequisite audit. Continue in
numeric order from IP-62: desktop contract, local support, tray/runtime integration,
Windows distribution, Linux distribution, and automated desktop acceptance.
Then perform the same-host private pilot. Retain an independent-machine pilot as
a separate later step before final system acceptance.

Private credentials and a live deployment are not prerequisites for implementing
or testing the new desktop features. They become prerequisites at the private
pilot, not reasons to halt public development now. No existing IP-01..IP-59
completion record or protocol state is redefined by this amendment.
